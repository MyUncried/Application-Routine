# features/migration

PRE-4 (story 1.2, AD-12, H24, FR-18-20 septième et huitième conséquences).

- `MigrationNoticeGate.tsx` — **unique lecteur** de l'avis de migration (`migration_notices`, écrit par `migration010`). Monté une seule fois dans `app/_layout.tsx`, à l'intérieur de `SessionServiceProvider` et jamais en `children` de `SQLiteProvider` (piège de l'écran blanc, AGENTS.md), une fois la base prête et le splash applicatif retiré. Il lit le repository par `MigrationNoticeRepositoryContext` (qui peut être nul au premier rendu : il attend) et, s'il existe un avis non acquitté, l'affiche par une `Alert` native à un seul bouton (`cancelable: false`). L'acquittement n'est écrit qu'à l'appui sur ce bouton : quitter l'application avant l'appui fait réapparaître l'avis au lancement suivant. Au plus un `Alert` par montage : une fois la lecture réglée, un changement de référence du repository ne relance rien ; si l'effet est nettoyé avant que la lecture ne se règle (changement de référence, double effet du mode strict), une seconde lecture peut avoir lieu, la première étant alors ignorée ; aucun `Alert` après démontage ; seul le genre `UNREADABLE_EXERCISES_DROPPED` est affiché, un genre inconnu est ignoré. Les erreurs de lecture ou d'écriture sont journalisées (`console.warn`) sans bloquer l'application. Ne rend rien.
- `formatMigrationNoticeMessage` — texte du lexique (`strings.migrationNotice`, RM-092) accordé au nombre : « 1 exercice illisible n’a pas pu être repris. » (singulier sans source, à valider par Hermann à la recette, AC4) ou « {n} exercices illisibles n’ont pas pu être repris. ». Aucun nom, identifiant ni contenu d'Exercice écarté. Le libellé du bouton (« OK ») n'a pas de source.

Rendu de l'`Alert` : primitive native, aucune frame Figma (NON VÉRIFIABLE) ; recette R-1.2-01.
