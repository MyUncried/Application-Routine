# 99 - Journal des modifications



## Version v6

### Ajouts
- Mise en place d'un registre permanent des décisions (chapitre 06).
- Introduction d'identifiants de décisions (D-001...).

### Processus
Chaque nouvelle livraison devra :
1. Mettre à jour le registre des décisions.
2. Mettre à jour le journal des modifications.
3. Lister les fichiers modifiés.
4. Vérifier que toutes les décisions validées sont intégrées.
